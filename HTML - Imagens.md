# Imagens

```html
<img src="./imagem.jpg" alt="Imagem" />
```

Para usarmos o elemento imagem, precisamos de duas propriedades corretamente configuradas. Primeiro o **`src`**, que define o caminho da imagem a ser carregada. O **`alt`** é uma descrição da imagem para leitores de tela, importante para acessibilidade.
