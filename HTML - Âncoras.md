# Âncoras

```html
<a href="https://exemplo.com" title="Exemplo">Exemplo</a>
```

É o elemento de *link* que conecta páginas a páginas (e torna a internet a internet).

Para funcionar, o elemento `<a>` precisa da propriedade `href` indicando para onde o *link* deve ir. Também é recomendado adicionar um `title`,  explicando mais sobre o link, importante para leitores de tela.

>[!tip] Dica
>Outras propriedades podem ser adicionadas a elementos HTML. Verifique mais no [Mozilla Developer Network](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
