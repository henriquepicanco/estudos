# Listas

```html
<ol>
	<li>Item 1</li>
	<li>Item 2</li>
	<li>Item 3</li>
</ol>

<ul>
	<li>Item 1</li>
	<li>Item 2</li>
	<li>Item 3</li>
</ul>
```

No HTML, existem **listas ordenadas**, `<ol>`, e **listas não ordenadas**, `<ul>`.

Dentro destes elementos de lista, os itens devem ser expressos dentro de elementos `<li>` (*list item*).

Podemos modificar os indicadores das listas usando propriedades na *tag* de abertura das listas. Em listas ordenadas, podemos ainda indicar por qual elemento a lista começa (por exemplo, começando a lista a partir da posição 5, ao invés da posição 1).
