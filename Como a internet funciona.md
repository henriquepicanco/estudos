# Como a internet funciona?

A internet é, num grosso modo, um **longo fio conectando computadores**, seja através de fibra ótica, geralmente chegando a casa do cliente de um provedor de internet, seja por grandes cabos submarinos que conectam os computadores entre diferentes continentes.

>[!tip] Os cabos submarinos
>É possível ver um mapa interativo que mostra como são as conexões entre continentes no site [submarinecablemap.com](https://www.submarinecablemap.com/)

Os computadores conectados a internet podem trocar informações entre si. E os computadores cuja função seja fornecer dados o tempo todo, como manter um site disponível para acesso a todo momento, são chamados de **servidores**. Já os computadores que se conectam a um servidor são chamados de **clientes**.

Todo computador conectado tem um endereço de IP. Este é um identificador único do computador na rede e com este podemos requerer informações de um outro computador. Entretanto, isto não é tão fácil de se usar para acessar um site, por exemplo. Por isto, costuma-se usar **domínios**, como *google.com*, para facilitar o acesso a sites específicos.

Ao requerer um *website*, fazemos uma requisição ao nosso provedor de internet, o **ISP**. O ISP irá, então, redirecionar esta requisição para um **servidor DNS**, um computador na rede cuja função é conectar domínios a IPs, como uma lista telefônica.
