# Parágrafos

```html
<p>Este é um exemplo de parágrafo.</p>
```

Sem esta tag, os textos ficariam totalmente embaralhados na tela, e deixaria a tarefa dos leitores de tela praticamente impossível de ser alcançada.

Também neste sentido, são essenciais para leitores de tela poderem pular parágrafos de um texto.
