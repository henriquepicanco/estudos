# Elementos void

```html
<hr />
<br />
```

São tags que se fecham em si mesmas, não tendo a estrutura tradicional de um elemento HTML normal.

Nos exemplos, **`<hr />`** desenha uma linha horizontal na tela, ideal para separar visualmente elementos HTML. Já o **`<br />`** quebra a linha num elemento parágrafo, ideal para poemas onde versos estão no mesmo parágrafo, mas que visualmente tem quebra de linha.

>[!tip] Dica
>Todas as tags void podem ser escritas sem a contrabarra (`<hr>`, `<br>`), mas recomenda-se usar a contrabarra para manter um aprendizado conciso.

>[!tip] MDN
>Sempre que houver uma dúvida sobre uma tag, deve-se consultar o MDN, o [Mozilla Developer Network](https://developer.mozilla.org/pt-BR/docs/Web/HTML), na seção sobre HTML.
