# Aninhamento e indentação

O **aninhamento** significa colocar elementos dentro de elementos HTML, como vimos nas [[HTML - Listas|listas]].

```html
<div> <!-- Este é um elemento que leva um elemento dentro de si. -->
	<p>Este é um elemento por si só</p> <!-- Este é um elemento. -->
</div>
```

Já a **indentação** é a forma visual de indicar elementos aninhados com espaços no início da linha. Este comportamento acontece em praticamente qualquer linguagem de programação.

```html
<div>
	<p>Este é um elemento</p><!--
^^^^ Este espaço é a indentação do elemento <p> dentro do elemento <div>
-->
</div>
```
